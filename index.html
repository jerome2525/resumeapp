Retainly GHL Bridge - OAuth Wrapper for GoHighLevel MCP Connector

  • Built a single-tenant remote MCP bridge that wraps GoHighLevel's bearer-token MCP server behind a full OAuth flow, so it can be added to Claude.ai (web, iPhone, Desktop) as a custom connector by pasting one URL
  • Implemented the complete OAuth 2.1 discovery + authorization stack from scratch - RFC 9728 protected-resource metadata, RFC 8414 authorization-server metadata, RFC 7591 dynamic client registration, RFC 7636 PKCE (S256), and resource indicators - with no database and no user accounts
  • Designed a fully stateless token system using signed JWTs (jose): short-lived auth codes (10 min) bound to the client's PKCE challenge, access tokens (1h), and refresh tokens (30d), all verified for signature, issuer, audience, and expiry
  • Engineered an authenticating reverse proxy that swaps the client's bearer header and re-signs each /mcp request with the shared GHL Personal Integration Token and locationId, streaming SSE responses through unbuffered, with redirect-URI validation and client_secret enforcement on the OAuth endpoints
  • Containerized with Docker and deployed on Railway for one-paste connector setup by a small team sharing one GHL sub-account
Outcome: Turns any bearer-token MCP server into a Claude-compatible OAuth connector, eliminating per-user credential setup and enabling secure, shared access from any Claude device.
